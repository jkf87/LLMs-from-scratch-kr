## 보너스 자료

- [02_bonus_bytepair-encoder](02_bonus_bytepair-encoder)에는 다양한 바이트 페어 인코더(byte pair encoder) 구현을 벤치마크하는 선택적 코드가 포함되어 있습니다

- [03_bonus_embedding-vs-matmul](03_bonus_embedding-vs-matmul)에는 임베딩 레이어(embedding layer)와 원-핫 인코딩된 벡터에 적용되는 완전 연결 레이어(fully connected layer)가 동일하다는 것을 설명하는 선택적(보너스) 코드가 포함되어 있습니다.

- [04_bonus_dataloader-intuition](04_bonus_dataloader-intuition)에는 텍스트보다는 간단한 숫자로 데이터 로더를 더 직관적으로 설명하는 선택적(보너스) 코드가 포함되어 있습니다.

- [05_bpe-from-scratch](05_bpe-from-scratch)에는 GPT-2 BPE 토크나이저를 처음부터 구현하고 훈련하는 (보너스) 코드가 포함되어 있습니다.
